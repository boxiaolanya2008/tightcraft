# 上下文治理模块 — 长会话不炸、成本受控

## Boundary 硬边界

- 会话内同一文件**内容最多完整读取一次**;仅首次与内容变化时读取。
- 记忆以**摘要 + 指纹**入表，不把全文压进上下文。
- 引用资源前先查表，指纹未变即复用，不重复读。
- 上下文趋近预算 → 主动降级(召摘要/删历史/停滞读)。

## Teaching 上下文治理最优做法

### 1. 锁存表(会话内，不展示)

| 路径 | 摘要 | 指纹 | 最后访问 |
|---|---|---|---|
| config/env.js | 导出项、关键常量 | a3f9… | now |

- **首次读** → 抽摘要、算指纹、入表。
- **再引用** → 查表;指纹未变直接用记忆。
- **失效** → 重算指纹，变了才重读并刷新。

### 2. 摘要化
- 只存支撑引用的量(变量名/导出/常量/契约)，不存实现细节。
- 需要完整细节时做**一次定向重读**,不全文回灌。

### 3. 预算失闸(truncate)

| 状态 | 处置 |
|---|---|
| 触顶在望 | 停止无关检索；改走摘要 |
| 已爆炸 | 丢弃低价值(过渡/客套/重复输出) |
| 跨阶段 | 总结前段为一段契约，不逐条转储 |

### 4. 检索收敛
- 命中答案即撤,不全文浏览。
- 同类多源只取结论，不重复抓取。

## Antipatterns 上下文治理坏味道(源头规避)

- **逐段全文重读** — 同一文件反复读，token 逐次烧。
- **整包入上下** — 把整文件压进记忆，挤空预算。
- **无视指纹失效** — 文件已改仍用旧态作答。
- **跨会话误当已锁存** — 新会话不自动继承，须重锁。
- **只增不减** — 全文、重复、无关内容不放，直到溢出。

## Good Example

读 `config.js` → 锁存 a3f9。20 步后再用，指纹未变 → 直接引用，零重读。上下文将满 → 移除过渡与已消化的整段,仅留契约摘要。

## Bad Example

每步都 `Read config.js` 全文;或文件已改仍引用旧 `{value}`;把两份大文档完整塞进上下文，后续无空间可读新文件。
