# 隔离式调试模块 — 定位不是猜

## Boundary 硬边界

- 先复现，后定位；**无最小可复现用例不进入根因**。
- 一次只改动一个变量；改前先召当前状态快照。
- 判定必须有可观察证据(日志、返回码、数据)，禁凭感觉下结论。
- 时间盒:单点长时间无进展 → 停下换假设，不执着。

## Teaching 调试最优做法

### 1. 复现优先
把"偶发/只在生产"压成可复现:
- 固定输入与前置状态；记录种子。
- 用最小数据/最小依赖触发，剔除无关部件。
- 复现命令写成脚本，可重复执行。

### 2. 二分定位(bisect)
在"输入端 → 输出端"链路上对半切断:
- 每次观察中间层输出，判断失真发生在哪半。
- 收敛到引入该行为的那个改动/函数，不扩大到无关区域。

### 3. 变量隔离
- **环境**:构造/中止替换(依赖桩、mock 外部调用)。
- **状态**:种子化 + 重置；观察可变状态的最小集合。
- **时间**:并发/竞态用确定化重放或强制交错，避免碰运气。

### 4. 证据链记录

| 观测 | 记录 |
|---|---|
| 实际输出 vs 期望 | 并置,标注首个差异点 |
| 前置判断 | 写上"若 A 则 B",用观测证/伪 |
| 根因 | 一句话机理 + 触发条件 |
| 修复 | 一行最小改 + 回归依据 |

### 5. 逐个假设淘汰
列 ≤2 个最可能假设 → 各自设计**反例探测** → 证据淘汰 → 收敛到唯一。剩余仍多 → 回复现。

## Antipatterns 调试坏味道(源头规避)

- **无复现开猜** — "可能是缓存/可能是网络"，不加证据。
- **一把梭改多处** — 同时动 3 处，无法归因。
- **只加打印不定判** — 输出无定罪标准，等于白打。
- **重启当修复** — 掩盖触发条件，遗漏真根因。
- **吞错归类** — `except: pass` 丢定位信息。
- **注意力跳跃** — 见不相干告警就换线，主链路未收敛。

## Good Example

报错:批量写入偶发 `deadlock`。
1. 固定种子 + 单线程压测 → 复现(~40 token)。
2. 二分:锁区间前/后 → 锁定"读-改-写非原子"。
3. 证据链:`日志显示 T2 读旧值再覆盖` → 判定竞态。
4. 最小改:引入版本号/条件更新 → 重跑种子用例绿。
5. 回归:并发度 10 压测，错误计数归零。

## Bad Example

"应该是死锁吧"，随手 `try: except: sleep(1)` 重试，不加复现用例；改动无关缓存配置；误关健康检查告警，主链路问题仍偶发。
