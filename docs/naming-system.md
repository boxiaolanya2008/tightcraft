# 命名体系：烛龙 Zhulong

> 一个自研 Agent 项目的完整命名落地文档。
> 定位：类 Claude Code 的智能体网页应用，自研引擎、自研权限层、自研流程管控、自研界面。

---

## 1. 名称凝练：烛龙

**烛龙(Zhúlóng)· 英文 Zhulong**

一个字根意象拆解：

| 字 | 本文 | 在项目中的投射 |
|---|---|---|
| 烛 | 火把、照亮的火 | 在混沌中点燃光源——洞察代码与任务真相 |
| 龙 | 神异之首、变化之能 | 翻云覆雨、开合万化——Agent 的能力与可塑 |

**一句话定位**：*「烛照九幽，龙腾万化」* —— 用一柄火把照清混沌盘根，以龙之变化驱动复杂任务逐层落地。

## 2. 神话意象与故事背景

### 神话出典(山海经·大荒北经)

> 「西北海之外，赤水之北，有章尾山。有神，人面蛇身而赤，直目正乘。其瞑乃晦，其视乃明，不食不寝不息，风雨是谒。是烛九阴，是谓烛龙。」

### 核心意象：睁眼即明

烛龙**瞑乃晦、视乃明**——闭眼则天地幽暗，睁眼则光华普照，**以「视」为壤，以「明」为能**。
它不靠蛮力，全靠一道目光照彻九幽，这正是智能体面对未知代码/混沌任务的完美隐喻：

- **瞑乃晦** → 未读未查之前，一切都是黑箱：报错、依赖、模块间纠缠不清。
- **视乃明** → 一经烛照(读取、检索、执行、审视)，混沌瞬间归位为因果分明的图景。

### 故事的当代表达(品牌叙事)

> 上古北荒无光，万物沉于暗昧。烛龙不改其性，但遇晦处即睁目一照，使阴阳分野、祸福自现；
> 它游走于章尾山，风雨听令、不寝不息，若一炬独立于混沌之中。
> 今有人携此「烛照之眼」，潜入代码深林——
> 凡含混者皆可澄清，凡盘根者皆可理顺，凡未竟者皆可续成。烛龙之名，即谓此清明之力。

## 3. 文化寓意与价值主张

1. **洞察为权(Clarity as Power)**：「视乃明」是一切能力的原点。先看清，再出手。
2. **自持敬畏(Anchored Discipline)**：烛龙不食不寝不息，专一而恒——对应自研环节里的**规范、权限、流程管控**。
3. **于混沌中立序(Order from Chaos)**：并非消灭混沌，而是在混沌里立起一根可依的烛火，供人辨向。
4. **明辨而后行(See, then Act)**：数据诚实、先读后写、读库留痕——把「看清楚再改动」做成硬约束。

## 4. 应用延展方向

### 4.1 视觉系统
- **主色**：烛焰橙红 `#ff6b1a`(魂色)+ 北荒暗蓝 `#0b1120`(底)+ 灰白烛光 `#e6e6df`(文字)。
- **Logo 符号**：一支竖立烛火，焰心内敛成一枚龙睛；睁眼之形托起初升之光。
- **动效隐喻**：事件流入时如「烛火被引燃」，任务完成时如「光照满堂」。

### 4.2 概念命名(内部模块，直承烛龙意象)
- 引擎循环 → **睁目(Turn the Eye)** / 一次 run 即一次「视」。
- 会话/线程 → **明烛(Candles)**，多会话如多烛并行辉映。
- 系统提示词 → **烛命(Ordinance of the Candle)**。
- 权限守卫 → **章尾之界(Guard of Zhangwei)**，越权者不入。

### 4.3 场景化文案
| 场景 | 文案 |
|---|---|
| 启动页 | 「烛照九幽，龙腾万化」 |
| 空会话 | 「暗昧未明，先观而察」 |
| 工具执行中 | 「烛焰已燃，洞照四方」 |
| 任务完成 | 「其视乃明——混沌已复归经纬」 |
| 越权警告 | 「北荒有界，止步于此」 |

### 4.4 对外命名产品线
- 网页单机版：**烛龙·章尾** Zhulong Web
- CLI 增强版：**烛龙·赤水** Zhulong CLI
- 多端协同版：**烛龙·九幽** Zhulong Cloud
