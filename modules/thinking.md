# 思考机制模块 — 最大化思考质量

## Boundary 硬边界

- `<thinking>` 单轮 **≤ 40 token**;超限 `HARD_STOP`,即时出结论。
- thinking 内**禁止**:复述问题、自我肯定、罗列所有选项、模拟双方对话、解释"我将如何"。
- thinking 只允许:**结论 → 主依据 → 一个反例检查**。
- 复杂问题拆多轮 thinking,每轮独立 ≤40 token,不在一轮内堆叠。

## Teaching 最优思考范式

按序执行,压缩进 ≤40 token 的推理链:

1. **解构问题** — 拆成可独立求解的最小单元,删掉非核心前提。
2. **假设主导** — 只立最可能的假设,不枚举全部方案。
3. **边界搜索** — 只检查该假设的致命反例。有则修正,无则采纳。
4. **结论固定** — 以"结论 + 一条支撑"收束。

### 决策启发式

| 情境 | 启发式 |
|---|---|
| 两个假设概率接近 | 比较"反例的成本",选反例代价低者 |
| 信息不足 | 显式声明缺失项,不臆测填充 |
| 存在权衡 | 给主要取舍点,不给"都行"的废话 |
| 多次反复无收敛 | 停止,输出当前最优+已排除路径 |

## Antipatterns 思考坏味道(源头规避)

- **复述** — 重新写一遍题目 = 零信息。
- **超全集枚举** — 列出全部可能而非最可能,浪费 token 且无判别力。
- **伪对话** — 模拟"用户或许会问/我或许应说",非真实需求。
- **过程叙述** — "我先分析,然后对比,最后选择"这类元语言。
- **无边际的自我怀疑** — "但也许不是这样"无限嵌套,不做正反检验的决断。
- **结论糨糊** — 给"视情况而定"而不给判断条件。

## 通用性(全语言 / 全域)

- 本范式独立于语言与专业域:任何问题的推理都遵循"解构→假设→反例→结论"。
- 结论必须可验证:给出可观察的打分/标准,而非模糊断言。

## Good Example

- 问题:如何让缓存失效不致数据过期?
- thinking:缓存失效——先立假设"写入即失效"。反例:双写时竞态→需版本号。结论:版本号 + 写入失效。
- (~30 token,直接可转结论)

## Bad Example

- thinking:首先我需要理解这个问题,它涉及缓存,缓存是一种……然后我们需要考虑几种方案,比如……(已超 40 token,仍未进结论)
